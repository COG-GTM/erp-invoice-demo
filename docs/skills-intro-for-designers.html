What Are Skills?

Repeatable procedures that standardize how work gets done

Definition

Skills are SKILL.md files committed to your repository. They teach AI agents repeatable, step-by-step procedures — from verifying design tokens to auditing UX copy. They follow the open Agent Skills standard and work across multiple AI tools.

How They Work

Designer describes a procedure ↓ Devin writes the SKILL.md file ↓ Team reviews via PR (like any code) ↓ Skill is auto-discovered in every session

Key Properties

  • Version-controlled — tracked in Git, reviewed via PRs
  • Auto-discovered — Devin finds them at session start
  • Parameterized — accept dynamic arguments via $ARGUMENTS
  • Open standard — 87,000+ skills on skills.sh

What Skills Do for Designers

Automate your workflow — from analysis to verification

Your Workflow, Automated

The Comarch UX team’s process — analyzing desktop behavior, researching competitors, creating drafts, verifying implementations — maps directly to Skills that run on demand:

Daily Verification (No Code)

  • cli-token-audit — Compare Figma spec tokens against CSS implementation
  • cli-ux-review — Scan modules for UX writing violations
  • cli-desktop-parity — Gap analysis: legacy desktop vs. web
  • cli-check-all — Run all three checks at once

Research & Analysis

  • system-analysis — Analyze validation rules, error states, edge cases
  • desktop-vs-web — Compare old & new system logic
  • research-benchmarking — Browse competitor ERPs, capture screenshots

Design Verification

  • figma-verification — Compare Figma designs against running app
  • ux-writing-review — Audit strings for glossary & tone compliance
  • test-before-pr — Pre-PR quality gate (lint, tests, tokens)

Real Impact

  • Designers verify implementations without writing code
  • Catch token drift, copy inconsistencies, and missing rules early
  • Support the full designer workflow: analysis → drafts → consultations → verification
  • Build a shared library the whole UX team benefits from

How to Create Skills

Describe it in plain language — Devin writes the file

Skill File Structure

--- name: figma-audit description: Compare Figma tokens against implementation. argument-hint: <figma-url> triggers: ["user", "model"] --- ## Step 1 Read the spec tokens ## Step 2 Compare against CSS ## Step 3 Output discrepancy report

Where Skills Live

Place files at
.agents/skills/<name>/SKILL.md
Devin discovers them automatically at session start.

Creation Steps

  • Describe your procedure to Devin in natural language
  • Devin generates the SKILL.md file
  • Devin opens a PR — your team reviews it like code
  • Once merged, it’s live — available to every session

Invoke a Skill

  • Mention by name: @skills:figma-audit
  • With arguments: @skills:cli-ux-review invoices
  • Or let Devin detect and invoke automatically

Getting Started

  • Run init-design-checks to scaffold verification skills for any repo
  • Complete the 9-lesson designer training (~55 min) to learn all three primitives
  • Browse 87K+ community skills at skills.sh
